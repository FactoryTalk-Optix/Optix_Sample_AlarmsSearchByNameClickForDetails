
## Project Description

This FTOptix sample project demonstrates how to implement **Alarms Search by Name with Click for Details** functionality. It provides an example of filtering and searching alarms by their name, and displaying detailed alarm information when the user clicks on a specific alarm entry in the HMI interface.
